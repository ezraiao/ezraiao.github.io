SOAR pipeline: from detection to block, no human in the loop

  1. Detect

    A scheduled Splunk search flags a suspicious source IP and fires a webhook.

  2. Enrich

    n8n looks the IP up in GeoIP and AbuseIPDB to get a location and abuse score.

  3. Decide and block

    Above the threshold, n8n tags the IP through the Palo Alto API. A dynamic address group picks it up and the block takes effect without a policy change.

  4. Notify

    A Discord message records what was blocked and why, so a person can review or undo it.
